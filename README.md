# MenQ

## 面接問答暗記アプリ

**MenQ（メンキュー）** は、面接でよく聞かれる質問と模範回答を登録し、ランダムに出題された質問に自分で回答することで、面接問答を繰り返し練習・暗記できるブラウザベースのWebアプリです。

**MenQ = 面接（Men）＋ Question / Q&A（Q）**

> **MenQ — 面接問答を、覚える。答えられる。**

## 概要

MenQは、面接で想定される質問と回答を自分で登録し、実際の面接を想定して繰り返し回答するための学習アプリです。

単に模範回答を読むのではなく、

```text
質問を見る
    ↓
自分で考える
    ↓
回答する
    ↓
模範回答と比較する
    ↓
不足部分を確認する
    ↓
ランダムに再出題する
```

という「思い出して答える」学習を中心に設計しています。

---

## コンセプト

MenQの目的は、面接回答を一字一句そのまま暗記することではありません。

重要なのは、

- 回答の結論
- 回答の理由
- 具体的な経験
- 成果
- 応募先での活かし方
- 面接で伝えるべきキーワード

を覚え、質問されたときに自分の言葉で自然に話せるようになることです。

そのためMenQでは、質問だけを見て回答し、その後に模範回答を確認する形式を採用しています。

## 使い方

### 1. MenQを起動

`index.html` をブラウザで開きます。

---

### 2. 問題を登録

「問題管理」を開きます。

以下の情報を登録します。

```text
質問
模範回答
カテゴリ
ヒント
キーワード
```

---

### 3. 問題演習

「問題演習」を開きます。

登録した問題からランダムに質問が出題されます。

例えば、

```text
Q. 自己PRをしてください。
```

と表示されます。

模範回答を見ずに、自分の回答を入力します。

---

### 4. 回答を提出

「回答を提出」をクリックします。

すると、

- 自分の回答
- 自己評価
- 模範回答
- キーワード

などを確認できます。

---

### 5. 次の問題へ進む

「次の問題」を押すと、次の問題がランダムに出題されます。

## 問題を登録する

例えば、以下のような問題を登録できます。

### 質問

```text
自己PRをしてください。
```

### 模範回答

```text
私の強みは、課題を整理して改善につなげる力です。

前職では業務の中で発生していた非効率な作業を
洗い出し、手順を見直しました。

その結果、作業時間を削減することができました。

御社でも課題を見つけるだけでなく、
周囲と協力しながら具体的な改善につなげていきたい
と考えています。
```

### カテゴリ

```text
自己紹介・自己PR
```

### ヒント

```text
強み → 具体例 → 成果 → 応募先でどう活かすか
```

### キーワード

```text
強み,課題,改善,成果,協力
```

## 問題を練習する

登録した問題はランダムに出題できます。

```text
質問
 ↓
自分で回答
 ↓
回答提出
 ↓
模範回答を確認
 ↓
不足部分を確認
 ↓
次の問題
```

このサイクルを繰り返すことで、実際の面接で質問されたときに答えやすくなります。

---

## 学習モード

### 全問題

登録されているすべての問題からランダムに出題します。

```text
📚 全問題
```

---

### 要復習

過去に「要復習」と判定された問題を中心に出題します。

```text
🔥 要復習
```

苦手な質問を重点的に練習できます。

---

### 未回答

まだ回答していない問題を出題します。

```text
🆕 未回答
```

新しく登録した問題を優先して練習できます。

## 回答評価

MenQでは、登録したキーワードを使って回答を簡易評価します。

例えば、

```text
強み
改善
成果
協力
```

というキーワードを登録している場合、回答に含まれるキーワードを確認します。

一定以上含まれていれば、

```text
🎉 正解候補！
```

不足している場合は、

```text
🔄 要復習
```

として記録します。

### 注意

この評価は、あくまで暗記・練習を補助するための簡易評価です。

実際の面接では、キーワードが含まれているだけで良い回答になるとは限りません。

以下のような要素も重要です。

- 話の一貫性
- 具体性
- 話す速度
- 声の大きさ
- 表情
- 応募先との関連性
- 面接官への伝わりやすさ

## LocalStorageについて

問題データはブラウザのLocalStorageに保存されます。

そのため、

- ページを閉じる
- ブラウザを再起動する

といった操作を行っても、通常は問題データを維持できます。

ただし、以下の場合にはデータが失われる可能性があります。

- ブラウザのサイトデータを削除した
- LocalStorageを削除した
- ブラウザのプロファイルを変更した
- プライベートブラウジング環境を利用した
- ブラウザ側の保存容量・保存ポリシーの影響を受けた

重要なデータは定期的にJSONバックアップしてください。

## 起動方法

### 方法1：直接起動

最も簡単な方法です。

```text
index.html
```

をブラウザで開きます。

ただし、ブラウザのセキュリティポリシーやCDN、PyScriptなどの仕様によっては、ローカルファイルとして直接開いた場合に正常動作しない場合があります。

---

### 方法2：Python HTTPサーバー

Pythonがインストールされている場合は、MenQのディレクトリで以下を実行します。

```bash
python -m http.server 8000
```

その後、ブラウザで以下を開きます。

```text
http://localhost:8000/
```

---

### 方法3：Visual Studio Code

Visual Studio Codeを利用している場合は、Live ServerなどのローカルHTTPサーバー機能を利用できます。

```text
index.html
    ↓
Live Server
    ↓
http://localhost:xxxx/
```

## プライバシーと注意事項

MenQは基本的にブラウザ内で動作します。

登録した問題・回答は、MenQ自身のバックエンドサーバーへ送信する設計ではありません。

ただし、以下には注意してください。

- 外部CDNからJavaScript/CSSライブラリを読み込みます。
- ブラウザのLocalStorageを削除するとデータが失われる可能性があります。
- 共有PCでは利用後にサイトデータを確認してください。
- 重要な面接情報はJSONでバックアップしてください。
- バックアップJSONには登録した回答内容が含まれる場合があります。
- CDNや外部ライブラリの利用時は、それぞれの利用規約・ライセンスを確認してください。

## 面接練習の基本

MenQでは、以下の流れで練習することを推奨します。

```text
① 問題を登録
      ↓
② 模範回答を登録
      ↓
③ キーワードを登録
      ↓
④ ランダム出題
      ↓
⑤ 質問だけを見る
      ↓
⑥ 自分の言葉で回答する
      ↓
⑦ 回答を入力する
      ↓
⑧ 模範回答を見る
      ↓
⑨ 足りない部分を確認する
      ↓
⑩ 要復習として再挑戦
```

という形にできます。

## ライセンス

MenQ自体のライセンスを設定する場合は、プロジェクトルートに `LICENSE` ファイルを追加してください。

例えばMIT Licenseを採用する場合は、

```text
MenQ/
├── index.html
├── README.md
└── LICENSE
```

とします。

また、外部CDN経由で利用するライブラリについては、それぞれのライセンス条件を確認してください。

## まとめ

MenQは、

> **「面接で質問されたとき、考えずに答えられる状態を作る」**

ことを目的としたシンプルな面接問答暗記アプリです。

模範回答を読むだけではなく、

```text
質問を見る
 ↓
思い出す
 ↓
自分で答える
 ↓
模範回答と比較する
 ↓
不足部分を復習する
 ↓
ランダムに再挑戦する
```

という学習サイクルを繰り返すことで、面接本番での回答力向上を目指します。
